# Posteingang Vorzimmer-Arbeitsliste V1

## Zweck

Dieses Modul erstellt aus dem aktuellen Posteingang eine Arbeitsliste für das Vorzimmer.

Es verschiebt keine Dateien und trifft keine Sachentscheidung. Es ordnet nur, welche Entscheidungen offen sind.

## Ausgewertete Bereiche

Ausgewertet werden insbesondere:

- Roh-Eingang
- Quarantäne
- Signaturprüfung
- Sprachprüfung
- Rückfrage an Absender
- Vorzimmerentscheidung
- technisch geprüfte Dateien
- Anwaltvorlage
- abgewiesene Eingänge

## Zulässige Entscheidungsrichtungen

Die Liste zeigt je Eingang die zulässigen nächsten Schritte, insbesondere:

- Produktionslauf starten
- nicht öffnen
- technische Nachprüfung
- Signaturprüfung
- Sprachprüfung
- Rückfrage an Absender
- Ersatzübersendung verlangen
- Anwaltvorlage
- Abweisung
- Archivierung

## Nachweise

Sicherheitsberichte und Sprachberichte werden als Nachweise herangezogen, soweit sie über die Eingangskennung zugeordnet werden können.

## Ergebnis

Die Arbeitslisten werden geschrieben nach:

`Windows_App\Logs\Vorzimmer_Arbeitslisten`

Erzeugt werden:

- TXT
- CSV
- JSON

## Leitregel

Das Vorzimmer entscheidet organisatorisch. Die Software bereitet die Entscheidung nur strukturiert vor.
