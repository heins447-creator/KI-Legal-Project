# Definition of Done

## Kriterien

Ein Modul gilt als fertig, wenn:

1. **Zweck definiert** – Das Modul hat einen klar dokumentierten Zweck.
2. **Eingabe/Ausgabe definiert** – Schnittstellen sind dokumentiert.
3. **Code geschrieben** – Der Code ist vollständig und kommentiert.
4. **Selbsttest bestanden** – Das Modul hat einen Selbsttest, der erfolgreich ist.
5. **Modultest bestanden** – Alle Modultests sind erfolgreich.
6. **Schnittstellentest bestanden** – Übergaben an andere Module sind getestet.
7. **Integrationstest bestanden** – Das Modul läuft im Gesamtsystem.
8. **Dokumentation vollständig** – Entwicklerdokumentation ist vorhanden.
9. **Lizenz geprüft** – Alle verwendeten Komponenten haben einen gültigen Lizenzstatus.
10. **Keine Warnungen** – Es gibt keine unbehandelten Warnungen.
