# ALIN Info-Button-Texte

## Grundsatz

Jeder Info-Button hat eine Kurzhilfe (Tooltip) und eine Langhilfe (Dialog).

## Texte

| Info-Button | Kurzhilfe | Langhilfe |
|-------------|-----------|-----------|
| Info Akten-ID | Eindeutige Kennung der Akte | Die Akten-ID ist die eindeutige Kennung der Mandantenakte. Sie wird automatisch vergeben oder manuell eingegeben. |
| Info Fristverdacht | Mögliche Frist erkannt | Das System hat einen Hinweis auf eine mögliche Frist erkannt. Bitte prüfen Sie das Dokument manuell. |
