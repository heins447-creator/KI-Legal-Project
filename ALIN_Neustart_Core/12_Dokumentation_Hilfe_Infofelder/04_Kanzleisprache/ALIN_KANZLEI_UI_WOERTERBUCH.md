# ALIN Kanzlei-UI-Wörterbuch

## Grundregel

Die Benutzeroberfläche verwendet ausschließlich Kanzleisprache.

## Begriffe

| Kanzleibegriff | Bedeutung |
|----------------|-----------|
| Briefkasten | Eingangsbereich für neue Dokumente |
| Posteingang | Liste der eingegangenen Dokumente |
| E-Akte | Digitale Akte |
| Akte | Mandantenakte |
| Mandant | Klient |
| Vorgang | Bearbeitungsfall |
| Dokumente | Eingereichte oder erzeugte Schriftstücke |
| Dateien | Einzelne Dateien eines Dokuments |
| Aufgabe | Zu erledigender Arbeitsschritt |
| Frist | Gesetzliche oder vereinbarte Frist |
| Fristverdacht | Hinweis auf mögliche Frist |
| Wiedervorlage | Zurückgestellte Bearbeitung |
| Vorlage an Anwalt | Übergabe an den Anwalt |
| Rücklauf an Sekretariat | Rückgabe an die Verwaltung |
| Zur Akte nehmen | In die Akte einordnen |
| Unterlagen nachfordern | Fehlende Dokumente anfordern |
| Sicherheitsprüfung | Technische Prüfung des Dokuments |
| Schlusskontrolle | Abschließende Prüfung |
| Verwaltungspost | Nicht mandantenbezogene Post |
| Notiz zur Akte | Vermerk |
| Auftrag an Sekretariat | Anweisung an die Verwaltung |
