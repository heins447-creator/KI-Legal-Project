# ALIN Windows-Offline-Gerichtslaptop V1

## Anforderungen

- Betrieb ohne Internetverbindung
- Keine Administratorrechte erforderlich
- Lokale Ressourcen
- Synchronisation mit Kanzlei-PC

## Synchronisation

### Büro → Gericht
- Akten und Dokumente exportieren
- Ressourcen und Cache aktualisieren
- Offline-Fallbacks prüfen

### Gericht → Büro
- Bearbeitete Dokumente importieren
- Entscheidungen und Notizen synchronisieren
- Audit-Protokoll übertragen

## Lokale Ressourcen

- OCR-Sprachpakete
- Übersetzungsmodelle
- Terminologien
- Quellen-Cache
- Skill-Modelle

## Einschränkungen

- Keine Online-Quellen
- Keine automatischen Updates
- Keine Cloud-Synchronisation
- Manuelle Ressourcen-Aktualisierung
