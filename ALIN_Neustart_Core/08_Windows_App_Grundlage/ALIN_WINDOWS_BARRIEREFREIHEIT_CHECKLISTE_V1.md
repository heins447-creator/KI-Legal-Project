# ALIN Windows-Barrierefreiheit-Checkliste V1

## Microsoft Accessibility Guidelines

- [ ] Tastaturbedienung für alle Funktionen
- [ ] Screenreader-Unterstützung (Narrator, NVDA, JAWS)
- [ ] Hoher Kontrast-Modus
- [ ] Skalierung 100 % bis 200 %
- [ ] Fokus-Indikatoren sichtbar
- [ ] Keine Blink-Elemente
- [ ] Ausreichender Farbkontrast (WCAG 2.1 AA)
- [ ] Beschriftungen für alle Steuerelemente
- [ ] Alternativtexte für Bilder
- [ ] Strukturierte Überschriften

## WCAG 2.1

- [ ] Wahrnehmbar: Informationen müssen wahrnehmbar sein
- [ ] Bedienbar: Komponenten müssen bedienbar sein
- [ ] Verständlich: Informationen müssen verständlich sein
- [ ] Robust: Inhalt muss robust sein

## Kognitive Anforderungen

- [ ] Klare Sprache
- [ ] Konsistente Navigation
- [ ] Fehlervermeidung
- [ ] Bestätigungen bei wichtigen Aktionen
- [ ] Hilfe und Erklärungen verfügbar

## Testumgebung

- Windows 10 mit Narrator
- Windows 11 mit Narrator
- Hoher Kontrast-Modus
- 200 % Skalierung
- Tastaturbedienung ohne Maus
