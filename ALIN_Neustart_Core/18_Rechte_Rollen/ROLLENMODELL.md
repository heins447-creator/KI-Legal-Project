# ALIN Rollenmodell

## Rollen

| Rolle | Beschreibung | Berechtigungen |
|-------|--------------|----------------|
| Sekretariat | Verwaltung, Posteingang, Rücklauf | Posteingang, Weiche, Rücklauf, Wiedervorlage |
| Anwalt | Rechtliche Bearbeitung | Anwaltsansicht, Entscheidungen, Notizen |
| Administrator | Systemverwaltung | Alle Funktionen, Register, Healthcheck |
| System | Automatisierte Prozesse | Modulaufruf, Statusänderung, Logging |
| Agent | KI-gestützte Bearbeitung | Skill-Aufruf, Vorschläge, keine Entscheidungen |
| Entwickler | Entwicklung und Wartung | Code, Tests, Debugging |

## Grundsatz

Jede Aktion ist einer Rolle zugeordnet und wird protokolliert.
