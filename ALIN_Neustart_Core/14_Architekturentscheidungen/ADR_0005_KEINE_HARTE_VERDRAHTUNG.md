# ADR 0005: Keine harte Verdrahtung

## Kontext

Fachmodule enthalten hart verdrahtete Tools, Sprachen, Quellen.

## Entscheidung

Keine harte Verdrahtung. Alle Ressourcen über ALIN-Core.

## Begründung

- Wartbarkeit.
- Flexibilität.
- Austauschbarkeit.

## Konsequenzen

- Module fragen ALIN-Core.
- Zentrale Register erforderlich.
