# ALIN Exportformate

## Unterstützte Formate

- PDF
- JSON
- CSV
- TXT

## Regeln

1. Export nur mit Freigabe.
2. Protokollierung: Wer, wann, was.
3. Kein Export von Originaldokumenten ohne Anonymisierung.
4. Kein Export von personenbezogenen Daten ohne Freigabe.

## Anonymisierung

- Namen entfernen
- Adressen entfernen
- Aktenzeichen entfernen
- IDs beibehalten (für Nachvollziehbarkeit)
