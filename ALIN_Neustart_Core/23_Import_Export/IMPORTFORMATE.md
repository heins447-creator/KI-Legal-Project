# ALIN Importformate

## Unterstützte Formate

- PDF
- TIFF
- PNG
- JPEG
- JSON
- CSV

## Regeln

1. Import nur aus vertrauenswürdigen Quellen.
2. Sicherheitsprüfung vor Import.
3. Protokollierung: Wer, wann, was.
4. Kein Import von ausführbaren Dateien.

## Sicherheitsprüfung

- Dateityp prüfen
- Virenscan
- Größenprüfung
