# ALIN Info-Button-Regeln

## Grundsatz

Jedes wichtige Feld und jeder kritische Button bekommt einen Info-Button.

## Regeln

1. Info-Buttons sind immer sichtbar, nie versteckt.
2. Kurzhilfe: Tooltip, maximal 200 Zeichen.
3. Langhilfe: Dialog mit ausführlicher Erklärung.
4. Sprache: Kanzleisprache, keine technischen Begriffe.
5. Bei Warnungen: Info-Button wird orange.
6. Bei Fehlern: Info-Button wird rot.

## Position

- Rechts neben dem Feld oder Button.
- Einheitliches Icon: (i) oder (?).

## Verhalten

- Hover: Kurzhilfe (Tooltip).
- Klick: Langhilfe (Dialog).
- Tastatur: Fokusierbar, Enter öffnet Langhilfe.
