# ALIN Support-Export-Regeln

## Grundsatz

Diagnosepakete dürfen keine Originaldokumente und keine vertraulichen Inhalte enthalten.

## Erlaubte Inhalte

- Logs (ohne Daten)
- Configs (ohne Secrets)
- Healthcheck-Berichte
- Versionsinformationen
- Fehlermeldungen

## Verbotene Inhalte

- Originaldokumente
- Mandantendaten
- Personenbezogene Daten
- API-Keys
- Passwörter
