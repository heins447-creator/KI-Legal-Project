# ALIN Backup-Konzept

## Grundsatz

Regelmäßige Backups aller wichtigen Daten.

## Was wird gesichert

1. Datenbank
2. Konfigurationen
3. Register
4. Logs
5. Originaldokumente (nur wenn erlaubt)

## Was wird nicht gesichert

1. Cache
2. Temporäre Dateien
3. Testdaten

## Häufigkeit

- Datenbank: Täglich
- Konfigurationen: Bei Änderung
- Originaldokumente: Bei Änderung

## Aufbewahrung

- Mindestens 30 Tage
- Mandantenbezogene Daten: Bis zur Mandatsbeendigung + 10 Jahre
