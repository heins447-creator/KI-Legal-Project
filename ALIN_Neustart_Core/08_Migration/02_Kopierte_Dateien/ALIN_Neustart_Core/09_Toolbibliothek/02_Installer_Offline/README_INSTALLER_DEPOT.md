# Installer-Depot

## Zweck

Dieses Verzeichnis enthält Offline-Installer für alle benötigten Tools.

## Regeln

- Nur offizielle Installer
- SHA256-Prüfsummen dokumentieren
- Lizenzen prüfen
- Keine modifizierten Installer

## Struktur

```
02_Installer_Offline/
├── OCR/
├── PDF/
├── Bildverarbeitung/
├── Übersetzung/
├── Windows-App/
├── Datenbank/
└── Sicherheit/
```
