# ALIN Lizenzstatus

## Grundsatz

Jedes Tool, Modell, Sprachpaket, Adapter und jede Quelle muss einen gültigen Lizenzstatus haben.

## Statuswerte

- freigegeben
- nur_interne_nutzung
- lizenz_pruefen
- kommerziell_klaeren
- gesperrt
- ersatztool_erforderlich

## Regel

Kein Tool darf verwendet werden, wenn der Lizenzstatus `gesperrt` oder `ungeklaert` ist.

## Pflichtfelder

Siehe `11_Lizenzen_Compliance/00_Lizenzregister/ALIN_LIZENZREGISTER.schema.json`.
