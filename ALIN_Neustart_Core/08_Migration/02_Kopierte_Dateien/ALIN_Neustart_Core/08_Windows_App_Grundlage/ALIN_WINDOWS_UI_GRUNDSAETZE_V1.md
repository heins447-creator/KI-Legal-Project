# ALIN Windows-UI-Grundsätze V1

## Fluent Design

- Material: Acryl, Reveal, Depth
- Bewegung: Sanfte Animationen, sinnvoll eingesetzt
- Skalierung: 100 % bis 200 %
- Kontrast: Hoher Kontrast unterstützt

## Farbschema

| Farbe | Hex | Verwendung |
|-------|-----|------------|
| Dunkelblau | #1a3a5c | Primärfarbe, Header, Navigation |
| Orange | #e67e22 | Akzente, Warnungen, Fristverdacht |
| Weiß | #ffffff | Hintergrund, Text auf dunklem Grund |
| Hellgrau | #f5f5f5 | Sekundärer Hintergrund |
| Dunkelgrau | #333333 | Text auf hellem Grund |

## Hauptansichten

1. **Sekretariatsansicht** – Posteingang, Weiche, Rücklauf
2. **Anwaltsansicht** – Dokumente, Entscheidungen, Notizen
3. **Dreiansicht** – Original / OCR / Übersetzung
4. **Rücklauf** – Status, Wiedervorlage, Nachforderung
5. **Healthcheck** – Systemstatus, Warnungen

## Kanzleisprache

- Briefkasten statt Posteingang
- E-Akte statt digitale Akte
- Mandant statt Klient
- Vorgang statt Fall
- Fristverdacht statt Fristwarnung
- Wiedervorlage statt Zurückstellung
- Vorlage an Anwalt statt Übergabe
- Rücklauf an Sekretariat statt Rückgabe

## Barrierefreiheit

- Tastaturbedienung für alle Funktionen
- Screenreader-Unterstützung
- Hoher Kontrast
- Skalierung
- Fokus-Indikatoren

## Info-Buttons

- Jedes wichtige Feld hat einen Info-Button
- Kurzhilfe: Tooltip
- Langhilfe: Dialog mit Erklärung
