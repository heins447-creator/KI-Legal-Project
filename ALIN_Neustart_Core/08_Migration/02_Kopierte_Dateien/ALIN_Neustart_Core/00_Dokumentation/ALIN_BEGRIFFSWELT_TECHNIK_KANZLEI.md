# ALIN Begriffswelt: Technik und Kanzlei

## Grundregel

Die Benutzeroberfläche verwendet ausschließlich Kanzleisprache. Technische Begriffe bleiben in Entwicklerdokumentation, Protokollen und Registern.

## Kanzleibegriffe (sichtbar in UI)

| Kanzleibegriff | Bedeutung |
|----------------|-----------|
| Briefkasten | Eingangsbereich für neue Dokumente |
| Posteingang | Liste der eingegangenen Dokumente |
| E-Akte | Digitale Akte |
| Akte | Mandantenakte |
| Mandant | Klient |
| Vorgang | Bearbeitungsfall |
| Dokumente | Eingereichte oder erzeugte Schriftstücke |
| Dateien | Einzelne Dateien eines Dokuments |
| Aufgabe | Zu erledigender Arbeitsschritt |
| Frist | Gesetzliche oder vereinbarte Frist |
| Fristverdacht | Hinweis auf mögliche Frist |
| Wiedervorlage | Zurückgestellte Bearbeitung |
| Vorlage an Anwalt | Übergabe an den Anwalt |
| Rücklauf an Sekretariat | Rückgabe an die Verwaltung |
| Zur Akte nehmen | In die Akte einordnen |
| Unterlagen nachfordern | Fehlende Dokumente anfordern |
| Sicherheitsprüfung | Technische Prüfung des Dokuments |
| Schlusskontrolle | Abschließende Prüfung |
| Verwaltungspost | Nicht mandantenbezogene Post |
| Notiz zur Akte | Vermerk |
| Auftrag an Sekretariat | Anweisung an die Verwaltung |

## Technische Begriffe (nicht sichtbar in UI)

| Technischer Begriff | Verwendung |
|---------------------|------------|
| Registry | Internes Register (Modul, Ressource, Skill, Tool, Lizenz) |
| Adapter | Schnittstelle zu externer Quelle |
| Resolver | Bestimmung von Ressourcen aus Kontext |
| Workflow Engine | Prozesssteuerung (intern) |
| Contract | Schnittstellenvertrag |
| Schema | Datenstrukturdefinition |
| Healthcheck | Systemprüfung |
| Pipeline | Verarbeitungskette (intern) |
| OCR-Backend | OCR-Verarbeitung (intern) |
| Resource Layer | Ressourcenverwaltung (intern) |
| Skill | Fähigkeit eines Agenten |
| Agent | Automatisierte Bearbeitungseinheit |

## Mapping: Technisch → Kanzlei

| Technisch | Kanzlei |
|-----------|---------|
| Pipeline | Bearbeitungsweg |
| OCR-Backend | Texterkennung |
| Resource Layer | Ressourcen |
| Healthcheck | Systemprüfung |
| Resolver | Zuordnung |
| Adapter | Verbindung |
| Schema | Datenformat |
| Contract | Übergaberegel |

## Dokumentation

- Entwicklerdokumentation verwendet technische Begriffe.
- Benutzerhandbuch verwendet Kanzleibegriffe.
- Info-Buttons in der UI erklären Kanzleibegriffe kurz und verständlich.
