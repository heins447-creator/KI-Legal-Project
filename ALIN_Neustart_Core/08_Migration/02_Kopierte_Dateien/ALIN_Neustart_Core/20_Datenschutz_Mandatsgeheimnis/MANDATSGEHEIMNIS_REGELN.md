# ALIN Mandatsgeheimnis-Regeln

## Grundsatz

Mandatsgeheimnis hat oberste Priorität.

## Regeln

1. Mandantenbezogene Daten nur lokal verarbeiten.
2. Keine Weitergabe an externe Modelle ohne Freigabe.
3. Keine Cloud-Speicherung ohne Freigabe.
4. Export nur mit Freigabe und Protokoll.
5. Löschung nach Mandatsende + 10 Jahre.

## Markierungen

Siehe `DATENSCHUTZ_MARKIERUNGEN.schema.json`.
