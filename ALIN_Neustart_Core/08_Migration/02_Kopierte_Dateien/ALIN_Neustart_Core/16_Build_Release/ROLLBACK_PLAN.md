# ALIN Rollback-Plan

## Voraussetzung

Jedes Release hat einen Rollback-Plan.

## Schritte

1. Vor dem Update: Backup der aktuellen Version.
2. Update durchführen.
3. Test durchführen.
4. Bei Fehler: Rollback auf vorherige Version.
5. Protokollierung aller Schritte.

## Verantwortlichkeit

Rollback nur durch Administrator oder automatisch bei kritischen Fehlern.
