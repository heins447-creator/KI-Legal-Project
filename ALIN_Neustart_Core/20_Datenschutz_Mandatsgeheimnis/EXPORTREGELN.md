# ALIN Exportregeln

## Grundsatz

Export bedarf einer Freigabe und Protokollierung.

## Regeln

1. Export nur mit Administrator-Freigabe.
2. Protokollierung: Wer, wann, was.
3. Kein Export von Originaldokumenten ohne Anonymisierung.
4. Kein Export von personenbezogenen Daten ohne Freigabe.

## Erlaubte Exporte

- Anonymisierte Statistiken
- Protokolle (ohne Daten)
- Konfigurationen
